Optional soundtrack files
=========================

Drop licensed audio files here with these exact names and the game will stream
them automatically (cross-faded), instead of the built-in procedural score:

  menu.mp3      title, menus, camera check, character / chapter select
  dialogue.mp3  story dialogue scenes
  battle.mp3    fights (loops)
  boss.mp3      fights when the enemy is below 35% HP (loops)
  victory.mp3   victory screen (plays once)

Any missing file falls back to the original music generated in the browser.
Only add audio you have the rights to use.
