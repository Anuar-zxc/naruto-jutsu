# Ishara

Ishara — учебное веб-приложение для первых шагов в дактильной азбуке Казахстана. На главной можно выбрать уроки с нуля или маршрут после недавней потери слуха, который начинается с текстовых карточек для общения. Интерфейс, карточки, текстовый перевод и ИИ-наставник доступны на казахском, русском и английском.

## Как попробовать

1. В разделе «Учиться» откройте три фотографии, затем пройдите визуальную викторину. В четырёх уроках доступно 12 букв.
2. В разделе «Практика» выберите В, Н, У, К или Ы, включите камеру и повторите форму руки на фото. Приложение отмечает совпадение после 700 мс удержания. Медиа и координаты руки обрабатываются в браузере.
3. В разделе «Перевод» переведите свой текст или откройте готовую карточку в крупном размере. Карточки и уроки работают без обращения к Alem LLM.
4. В разделе «ИИ-наставник» задайте текстовый вопрос. XP начисляется за первое выполнение задания, а ежедневная цель и серия учитывают активность в этом браузере.

Камера сверяет статические положения кисти. Уроки охватывают часть дактильной азбуки. Перевод работает с письменным текстом, уроки посвящены жестовой азбуке.

## Запуск

Требуется Node.js 24.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Для наставника и произвольных переводов укажите `ALEM_API_KEY` в `.env.local`. На Vercel ключ хранится в переменных окружения проекта. API использует модель `alemllm` и ограничивает длину запросов. Для доступа к камере нужен localhost или HTTPS.

```sh
npm run typecheck
npm test
npm run build
```
